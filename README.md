# Flight Delay Prediction: project website

A small static website (plain HTML and CSS, no build step) that presents my flight arrival delay
prediction project from Introduction to Data Analytics: the task, the hidden pattern in the data
files, the seven models, and the limits of the result.

- **Pages:** `index.html` (overview), `finding.html`, `models.html`, `limits.html`, `comments.html`
- **Styles:** `style.css`
- **Script:** `explorer.js` (the interactive sliders on the Finding page)
- **Figures:** `figures/` (PNG exports of the report figures)
- **Report:** `report.pdf`

The code, notebook and report source live in the project repository (linked from the site).
The course data files are not included.

To view locally, open `index.html` in a browser.
